# The Only Connection You Need Is God 🕊️

A spiritual and meditative web experience reflecting on the eternal connection between the soul and God.

> *"The only connection you need is God."*

## ✨ Features
- **Sacred Wi-Fi Signal Emblem**: An animated, glowing celestial signal wave that symbolizes an eternal frequency.
- **Divine Network Attributes**:
  - **Zero Latency**: Every prayer and quiet thought is immediately known and heard.
  - **Infinite Range**: Reaching across every corner and season of life.
  - **Unbreakable Bond**: A connection that never buffers, disconnects, or fails.
- **Centering & Breathwork Guide**: Interactive 4-step breathing cycle (*Inhale, Hold, Exhale, Be Still*) with soothing visual feedback.
- **Cast Your Cares (Burden Release)**: An interactive prayer surrender tool that lifts worries upward into heaven with glowing light effects.
- **Scripture & Promise Generator**: Direct promises from sacred scripture for strength, peace, and hope.
- **Web Audio 432 Hz Ambient Drone**: Native in-browser harmonious 432 Hz synthesizer for calm contemplation.
- **Drifting Light Canvas**: Pure HTML5 canvas animation of golden rising sparks.

## 🚀 Getting Started
Simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/AjayBadhe850/wifi.git
cd wifi
```
Open `index.html` directly or launch a local preview.
